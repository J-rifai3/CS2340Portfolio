# Jude Rifai — CS 2340 Portfolio

Short portfolio: About Me, GT Movies Store, and a video demonstration slot.

## Open locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

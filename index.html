GT Movies Store

What it is

GT Movies Store is a Django web app for browsing and buying movies. Visitors can search the catalog, add titles to a cart, and create an account. After logging in, they can write, edit, or delete their own reviews, report other users' reviews, check out movies, and view past orders. Administrators can manage movies, reviews, and orders. All of these features came from user stories, detailing exactly what the user wanted to see in the app they were requesting I build.

The source is on GitHub, and the site is hosted on PythonAnywhere.

How it was made

The project is split into four Django apps that share one base template: home, movies, accounts, and cart. Movies and reviews are stored in the database. The cart stays in the session until a purchase creates order and item records. Login is required for reviews, checkout, and order history. Users can edit or delete only their own reviews; they can report other people's.

Process

I followed Django 5 for the Impatient chapter by chapter: project setup, the shared layout, the database, authentication, reviews, the cart, and orders. I finished each part and clicked through it before starting the next. When something broke—Django's folder structure, image uploads, review permissions, or PythonAnywhere static files—I isolated that piece, looked up online on how to fix it, fixed it, and then tested the feature again. The last step of the process was adding a report feature to user comments and getting the site online on PythonAnywhere.
